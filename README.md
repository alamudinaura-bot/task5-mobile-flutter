# Tugas 5 Mobile Developer - Aplikasi Katalog

Aplikasi Flutter sederhana yang terdiri dari 2 screen, screen pertama menampilkan 3 card katalog barang dan screen kedua menampilkan detail produk/barang.  Tujuannya adalah mendemonstrasikan navigasi antar screen (Stack Navigation) dan manajemen state interaktif.

## Fitur Utama
1. **Screen 1 (Beranda):** Menampilkan daftar 3 produk menggunakan `StatelessWidget`, `ListView`, dan `ListTile`.
2. **Navigasi:** Perpindahan ke Screen 2 menggunakan `Navigator.push`.
3. **Screen 2 (Detail Katalog):** Menampilkan detail produk menggunakan `StatefulWidget`, `Column`, `Container` warna pastel, serta tombol interaktif (state) dan tombol kembali (back).
